# AdvancedVillages
Advanced guild-based villages. Create, develop, and defend your village. A plugin designed for servers with a larger number of players.

## Features
- Fully customize all commands (name, aliases, subcommands)
- Customize all village build with worldedit
- Customizable addons: tablist, scoreboard, antilogout
- Customizable all GUIS
- Ranking kills, assists, deaths
- Upgrade village with economy, exp, materials
- Set village tag
- Database h2, mysql, mariadb
- Public API with cancelable Events

## Addons
- Tablist
- Scoreboard
- Spawn command
- Antilogout
- Chat format

_All addons can be disabled_

## Requirements
- Java 16+
- Minecraft Server Version 17+
- Economy plugin (Vault, Essentials, PlayerPoints)

## Optional plugins for better experience
- [PlaceholderAPI](https://modrinth.com/plugin/placeholderapi) - For Scoreboard and Tablist
- [WorldEdit](https://modrinth.com/plugin/worldedit) - Editing and creating village turrets/builds
- [WorldGuard](https://modrinth.com/plugin/worldguard) - Blocking entering area in Antilogout
- _Any economy from this list:_
- [Vault](https://www.spigotmc.org/resources/vault.34315/)<br>
- [Essentials](https://modrinth.com/plugin/essentialsx)<br>
- [PlayerPoints](https://modrinth.com/plugin/playerpoints)
