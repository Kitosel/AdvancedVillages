STRUCTURE ANIMATOR - FUTURE INTEGRATION

The class is currently standalone and is not created or used by AdvancedVillages.

1. Create one instance when the plugin starts:

StructureAnimator animator = new StructureAnimator(plugin);

2. Convert a turret or schematic to relative blocks. Every block uses offsets from
the village or outpost core:

List<StructureAnimator.StructureBlock> blocks = List.of(
    StructureAnimator.StructureBlock.of(Material.STONE, 0, -1, 0),
    StructureAnimator.StructureBlock.of(Material.OAK_PLANKS, 0, 0, 0)
);

For internal TurretStructure builds, expose an immutable copy of its placements and
map their material or BlockData to StructureBlock. For WorldEdit builds, read the
clipboard region and subtract its origin from every block position.

3. Start the animation on the Bukkit server thread:

StructureAnimator.AnimationSettings settings =
    new StructureAnimator.AnimationSettings(2L, 32, false, true);

StructureAnimator.Animation animation = animator.animate(
    coreLocation,
    blocks,
    settings,
    () -> plugin.getLogger().info("Structure finished")
);

The blocks are sorted by relative Y and built from bottom to top. A new height layer
starts on a later scheduler run. blocksPerTick limits large layers, periodTicks controls
animation speed, applyPhysics controls physics while building, and refreshAtEnd updates
connections such as fences, walls and glass panes.

4. Keep the returned Animation if a village or outpost can be removed during building.
Call animation.cancel() before removal. Call animator.cancelAll() in onDisable.

5. Before enabling this publicly, decide what should happen after a server restart.
The simplest safe option is to finish the structure instantly during shutdown or startup.
Another option is to persist the structure id, origin and current cursor.
